DOLL 3-MONTH SURPRISE WEBSITE

1. Extract this ZIP.
2. Open index.html to preview.
3. On GitHub, create a new public repository.
4. Add file > Upload files > upload index.html and README.txt > Commit changes.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Wait for GitHub Pages to publish, then share the website link or make a QR code for that link.
